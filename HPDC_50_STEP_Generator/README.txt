HPDC 50 STEP Generator (FreeCAD Macro)

This package generates 50 simple, distinct practice CAD solids and exports them as STEP files.

How to run:
1. Install FreeCAD.
2. Open FreeCAD and create a new macro.
3. Copy the contents of HPDC_50_STEP_Generator.FCMacro into it (or open the file as a macro if your FreeCAD version supports it).
4. Run the macro and select an output folder.
5. The macro exports 50 STEP files. Open each STEP in SolidWorks and use Save As > SLDPRT if needed.

Important:
- These are simplified educational geometries, not exact automotive components.
- They are not verified HPDC-manufactured parts; names identify intended practice categories only.
- STEP files are neutral CAD exchange files, not native .SLDPRT files.
- For a real supervised HPDC parameter model, each component needs reliable process-parameter labels.
